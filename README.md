# Insert Node at Specific Position in Circular Linked List

A Java program to insert a new node at a given position in a circular linked list.

## Features

- Creates a circular linked list
- Takes a value and position from the user
- Inserts the new node at the specified position
- Displays the updated list

## Technologies Used

- Java
- Scanner
- Circular Linked List

## Concepts Used

- Nodes
- Circular traversal
- Node insertion
- References
- Position handling

## Output

Original Circular Linked List:
10 -> 20 -> 30 -> 40 -> HEAD

Enter value to insert: 25
Enter position: 3

After insertion:
10 -> 20 -> 25 -> 30 -> 40 -> HEAD
